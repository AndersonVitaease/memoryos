# Biblioteca Oficial do MemoryOS

Esta pasta é a **Biblioteca Oficial** do MemoryOS.

Todos os documentos aqui presentes são considerados **fontes oficiais** do projeto.

## Ordem de Leitura

1. **MV** — MemoryOS Vision
2. **MPS** — MemoryOS Product Specification
3. **MAS** — MemoryOS Architecture Specification

9. **Architecture Auditor Specialist**

## Fonte de Conhecimento Institucional

Esta pasta é a principal fonte de conhecimento institucional do MemoryOS.

Futuras implementações, especialistas e auditorias deverão utilizar estes documentos como referência oficial.

## Alterações

Qualquer alteração nos documentos desta pasta deve ser tratada como uma **decisão arquitetural formal**, seguindo o processo de ADR definido em `docs/01-adr/`.

Estes documentos não devem ser modificados de forma leviana.
