# Project Memory

Este diretório contém a memória viva do projeto MemoryOS.

Diferente da **Biblioteca Oficial** (arquivada em `_archived/00-official-library-PRE-FOUNDATION/` — ver `src/docs/foundation/` para a especificação atual), que continha documentos institucionais estáveis, a Memória do Projeto é dinâmica: registra decisões recentes, reuniões, roadmap e backlog.

## Estrutura

- **Decisions.md** — Decisões de produto e engenharia recentes.
- **Meetings.md** — Registros de reuniões.
- **Roadmap.md** — Planejamento de entregas.
- **Backlog.md** — Itens pendentes e priorizados.

## Princípio

A Memória do Projeto **nunca** substitui a Biblioteca Oficial.

Decisões consolidadas que se tornam permanentes devem ser promovidas para a Biblioteca Oficial através de um ADR.
