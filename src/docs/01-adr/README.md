# Architecture Decision Records (ADR)

Este diretório contém os registros formais de decisões arquiteturais do MemoryOS.

Cada ADR documenta uma decisão significativa: seu contexto, alternativas consideradas e justificativa.

## Quando criar um ADR

- Decisões que afetam a arquitetura do Core.
- Escolhas que impactam a separação de responsabilidades.
- Adoção ou substituição de tecnologias.
- Mudanças em interfaces oficiais definidas no MAS/MES.

## Convenção de nomenclatura

`ADR-XXX-Título-Em-Kebab-Case.md`

## Status de um ADR

- `Proposed` — Em discussão.
- `Accepted` — Aprovado e em vigor.
- `Deprecated` — Substituído por ADR mais recente.
- `Superseded` — Substituído (referenciar o ADR que o substituiu).
