# CODE_OF_CONDUCT.md
## MemoryOS Code of Conduct

---

## Nosso Compromisso

O projeto MemoryOS está comprometido em fornecer um ambiente aberto, respeitoso e colaborativo para todos os participantes.

---

## Nossos Padrões

**Comportamentos esperados:**
- Usar linguagem respeitosa e inclusiva
- Aceitar críticas construtivas com abertura
- Focar no que é melhor para a plataforma
- Demonstrar empatia com outros contribuidores

**Comportamentos inaceitáveis:**
- Linguagem ou imagens ofensivas
- Ataques pessoais ou políticos
- Assédio público ou privado
- Publicação de informações privadas sem permissão

---

## Aplicação

Instâncias de comportamento inaceitável podem ser reportadas ao Core Team.

Todas as reclamações serão investigadas e respondidas de forma justa e discreta.
